# AMR 환경 안전 모니터링 관제 시스템

산업현장을 순찰하는 자율주행 차량(AMR/AGV)에 탑재된 열·광도·습도 센서의 데이터를
실시간으로 모니터링하고, 임계치 초과 시 경보(램프/부저/오디오)를 발생시키는
클라이언트 전용 대시보드입니다. 백엔드/DB 없이 브라우저 상태와 가상 데이터
시뮬레이션만으로 동작하며, Vercel에 정적/서버리스 배포가 가능합니다.

## 기술 스택

- Next.js 14 (App Router)
- React 18 (Hooks: `useState`, `useEffect`, `useMemo`, `useRef`)
- Tailwind CSS (다크 테마, 커스텀 애니메이션)
- lucide-react (아이콘)
- Web Audio API (실제 오디오 경보 토글)

## Vercel 배포

1. https://vercel.com 접속 후 GitHub 계정으로 로그인
2. "Add New... → Project"에서 방금 업로드한 저장소 선택
3. Framework Preset은 자동으로 "Next.js"로 인식됨 (별도 설정 불필요)
4. "Deploy" 클릭 → 몇 분 내로 배포 URL 발급

별도의 환경 변수나 데이터베이스 연결이 필요 없습니다. 모든 센서 데이터는
`components/Dashboard.jsx` 내부의 `setInterval` 시뮬레이션으로 생성됩니다.

## 주요 기능

- **차량 상태/위치 시뮬레이터**: 5개 구역(변전실/모터룸/배전반/펌프실/복도)을
  왕복 순찰하는 차량 위치를 트랙 애니메이션으로 표시
- **실시간 센서 카드 3종**: 온도(°C) / 광도(Lux) / 습도(%) — 2.5초마다 값이
  갱신되며, 약 16% 확률로 임계치를 초과하는 이상 이벤트 발생
- **임계치 설정 패널**: 슬라이더 + 숫자 입력으로 3개 센서의 경보 기준값을
  실시간 변경 가능
- **AI 관제 도우미 (업그레이드)**: 실시간 관제 데이터 질의 + 산업현장 안전·설비
  전반에 대한 지식 질의를 모두 처리하는 하이브리드 응답 엔진
- **중앙 처리 경보 시스템 (강화)**: 대형 램프/부저 + 이상 발생 위치·항목·수치·
  원인·조치 텍스트 표시 + 최근 경보 이력
- **이벤트 로그**: 구역 진입/위험 발생/해제 이력을 타임스탬프와 함께 기록

## AI 챗봇 응답 엔진

`components/knowledge.js` 에 10개 분야 42개 주제의 산업현장 지식베이스가
분리되어 있습니다.

| 분야 | 포함 주제 |
| --- | --- |
| 안전사고 대응 | 화재, 폭발/분진폭발, 감전, 끼임·협착, 추락, 넘어짐, 화상 |
| 전기설비 | 아크 플래시·코로나, 배전반·수변전실, 절연·접지, 정전기, 전력품질 |
| 기계설비·예지보전 | 베어링·모터 과열, 진동 진단, 펌프·캐비테이션, 컨베이어, 압축기·유압, 예지보전 전략 |
| 밀폐공간·유해가스 | 밀폐공간 질식, 유해가스 누출, 환기·국소배기 |
| 화학물질·환경 | MSDS·GHS, 화학물질 유출 방제 |
| 물류·장비·로봇 | 지게차, 크레인·양중, AGV/AMR, 산업용·협동로봇 |
| 작업안전관리 | LOTO, 위험성평가, 작업허가서·화기작업, 보호구, TBM·아차사고 |
| 산업보건 | 소음성 난청, 분진·용접흄, 온열·한랭질환, 근골격계 |
| 법규·제도 | 산업안전보건법, 중대재해·사고 보고 |
| 스마트팩토리 | IoT 모니터링 설계, 열화상 진단, PLC/SCADA, OT 보안 |

응답 순서는 다음과 같습니다.

1. **라이브 인텐트 매칭** — 센서 값, 차량 위치, 경보 상세, 임계치, 로그 등
   대시보드 실시간 데이터로만 답할 수 있는 질문을 먼저 처리
2. **지식베이스 검색** — 키워드 길이 가중 점수 방식으로 가장 적합한 주제를 선택
   (여러 키워드가 걸리면 가중치 추가, 관련 주제도 함께 추천)
3. **연계 안내** — 지식 답변 주제가 현재 발생 중인 경보와 연관되면
   "지금 실제로 해당 경보가 발생 중"이라는 실시간 상황을 덧붙임
4. **폴백** — 매칭 실패 시 질문 예시와 '도움말' 안내

지식 항목을 추가하려면 `KNOWLEDGE` 배열에 `{ id, cat, topic, keys, answer }`
객체를 하나 추가하면 됩니다. 별도 코드 수정은 필요 없습니다.

## 중앙 처리 경보 시스템

- **대형 경고 램프**: 하우징(112~128px) + 렌즈(64~76px) 2중 구조, 위험 시
  적색 점멸 + 3중 파동(ripple) 확산 + 글로우, 정상 시 녹색 상시 점등
- **대형 부저**: 96~112px 원형 아이콘, 위험 시 진동(shake) 애니메이션,
  오디오 경보 활성 시 음파 링 표시
- **이상 발생 상세 내역**: 감지된 항목마다 아래 정보를 텍스트로 출력
  - 심각도(경고/위험/치명 — 임계치 초과율 10%/25% 기준)
  - 고장 코드(TMP-HI / LUX-HI / HUM-HI)
  - **발생 위치**(구역명) 및 발생 시각
  - 문제 내용(설비 과열 / 이상 섬광(아크·코로나) / 누수·결로)
  - 측정값 · 임계치 · 초과율 · 최고값
  - 대상 설비, 추정 원인, 권장 조치
- **최근 경보 이력**: 최대 5건까지 시각·구역·항목·수치·심각도 요약 보관
- 동일한 정보를 챗봇도 공유하므로 "어디에 무슨 문제야?"라고 물으면
  경보 패널과 동일한 상세 내용을 답변합니다.

## 커스터마이징 포인트

- 순찰 구역: `components/Dashboard.jsx`의 `ZONES` 배열
- 센서 범위/기본 임계값: `SENSOR_CONFIG` 객체
- 색상 팔레트/애니메이션: `tailwind.config.js`의 `theme.extend`
- 챗봇 지식 항목: `components/knowledge.js`의 `KNOWLEDGE` 배열
- 경보 심각도 기준: `components/Dashboard.jsx`의 `severityOf()` 함수
- 고장 코드/원인/조치 문구: `SENSOR_CONFIG`의 `code`/`fault`/`cause`/`action`
